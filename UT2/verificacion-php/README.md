# Laboratorio de verificación de software — PHP 8.4.27

**UT2 · Seguridad activa frente a amenazas de sistemas y redes**

## Descripción

Este repositorio contiene un archivo de laboratorio asociado a **PHP 8.4.27**, destinado a una actividad práctica de ciberseguridad para estudiantes de Desarrollo de Aplicaciones Multiplataforma (DAM) y Desarrollo de Aplicaciones Web (DAW).

El objetivo es analizar la **integridad y autenticidad del software** antes de autorizar su utilización en un entorno profesional.

## Archivo disponible

`php-8.4.27-laboratorio.tar.xz`

## Actividad

El alumnado deberá utilizar herramientas de verificación criptográfica y contrastar los resultados con la información publicada por el proyecto oficial PHP.

A partir de las evidencias obtenidas, tendrá que justificar si autorizaría la utilización del archivo en el servidor de un cliente.
